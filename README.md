# JustAnotherCarMetaLibrary
This Library contains (mostly up to date) jsons with car meta for many countries featured in geoguessr. It will continue to be updated with new countries and new coverage. If you have a special request please send me a dm per discord: gruen132

To get the folders working download the mapmaking folders script for tampermonkey (https://greasyfork.org/en/scripts/571049-map-making-folders) and click import above your tags selecting the folder json file.
